# Leaving things as you found them

Keep the handle a wrap function returns and use it for everything a
patch needs after it is installed: `is_wrapped_by` to ask whether it
is still there, `wrapper_chain` and `unwrapped` to see what is stacked
on a target, and `unwrap_object` to take it out. Two patches removed
in either order, a patch through a subclass removed with nothing left
behind, and the one arrangement removal refuses, a plain closure over
the top, with the error that says so.

Twenty minutes, in a notebook with the code being patched open beside
it. The workshop installs wrapt into an environment of its own.
