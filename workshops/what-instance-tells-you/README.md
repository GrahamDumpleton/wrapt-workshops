# What instance tells you

Put one decorator on a plain function, an instance method, a class
method, a static method and a class, call each, and read what the
`instance` argument holds. See why `args` never contains `self`, why a
call through the class looks no different, and the one ordering rule
for `@classmethod`.

Fifteen minutes, in a notebook. The workshop installs wrapt into an
environment of its own.
